### HiTo — плагин для Civil 3D

Таблицы-легенды и блоки из DWG-шаблона, сетки осей с марками и размерными цепочками,
выноски и обозначения, листы из заготовок, калькулятор по объектам чертежа и нормоконтроль
схем. Сделан для исполнительной геодезической документации.

**[Скачать и описание](https://github.com/Hishwaia/HiTo-update)** · [English](https://github.com/Hishwaia/HiTo-update/blob/main/README.en.md)

Требуется Civil 3D 2027 и новее. Использование в работе бесплатно.

Связь: hitoplugin@gmail.com или [Issues](https://github.com/Hishwaia/HiTo-update/issues).
